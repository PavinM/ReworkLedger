# ReworkLedger

## Purpose
Track delivered modules, defects, corrective work, approvals, and proposed payroll adjustments.

## Frontend
React + Vite + TypeScript + Tailwind CSS

## Backend
Node.js + Express + TypeScript

## Database
MongoDB + Mongoose

## Main modules
1. Authentication and role-based access
2. Projects and tasks
3. Defect reporting and reopening
4. Corrective time tracking
5. Payroll calculations
6. Audit trail
7. Reporting and insights

## Core business rules
- Preserve original delivery history.
- Link defects to their original tasks.
- Separate corrective hours from new development.
- Require approval for corrective hours.
- Prevent duplicate payroll adjustments.
- Record justified exemptions.
- Maintain an auditable review trail.
